# Город 21

## Как открыть сайт

1. Распакуйте архив.
2. Откройте файл `gorod21/index.html` в браузере.
3. Для редактирования используйте HTML, CSS и JavaScript файлы в этой папке.

Для размещения на своём хостинге загрузите содержимое папки `gorod21`.

Интерактивный прототип проекта для CASE-IN. Предлагаемый пилот — один район Чебоксар.

## Возможности

- Изометрическая карта центра Чебоксар с географической формой залива, 905 зданиями и 924 отрезками улиц и дорожек.
- Три переключаемых уровня: над землёй, на земле, под землёй. Неактивные элементы города остаются полупрозрачными.
- Подсветка водопроводных сетей, дорог, фасадов и освещения на соответствующем уровне.
- Карточки с ограничениями, статусом, организацией, плановым сроком, источником и временем обновления.
- Связанные этапы: ремонт водопровода, раскопки, восстановление асфальта.
- Поиск улиц и событий, перемещение, масштаб, поворот, 2D/3D.
- Подписки, дом с радиусом внимания, создание обращения. Данные пользователя сохраняются локально в браузере.
- Адаптивный интерфейс и управление с клавиатуры.

## Демонстрационные данные

События, инженерные сети, сроки, источники сообщений и ответственные организации условные. Реальные службы, модерация и push-уведомления не подключены. Демо-обращения не отправляются за пределы браузера и не публикуются на карте. Адрес дома может отмечаться приблизительно по улице, когда номер отсутствует в исходных данных.

## Географические данные

Геометрия `city-data.js` получена 14 октября 2026 из API OpenStreetMap для области 47.205–47.260° E, 56.136–56.160° N. Производная географическая база распространяется на условиях [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

Для компактности геометрия упрощена; высоты зданий визуально ограничены. Условные трубопроводы построены вдоль части дорожных линий и не являются схемой настоящих коммуникаций.

## Структура

Статический сайт без сборки и внешних зависимостей во время работы. Готовые файлы сайта находятся в корне проекта.

- `index.html` — интерфейс и диалоги.
- `styles.css` — адаптивное оформление и переключение прозрачности.
- `map.js` — SVG-отрисовка города и навигация.
- `app.js` — демонстрационные события и действия пользователя.
- `city-data.js` — геометрия улиц, водоёмов и зданий.
- `assets/` — локальные шрифты Manrope и значок сайта.

Проверены синтаксис JavaScript, целостность ресурсов, SVG-отрисовка трёх уровней и основные действия интерфейса в DOM-окружении. Просмотр в полноценном браузере при создании был недоступен.
